# 一分钟即兴表达

一个中文即兴表达练习网页。随机抽取一个概念，例如「煤气灯效应」或「幸存者偏差」。用 10 分钟查资料、理思路，再用自己的话讲 1 分钟。准备好后也可以提前开讲。

## 使用

下载项目后用浏览器打开 `index.html`。点击「随机抽题」，选定题目后点击「开始准备」。准备倒计时结束后自动进入讲述，讲述完成后可以继续抽题。每轮结束后，用一句话记下下一轮想改进的一点。

内置题库包含 152 个概念。练习时只显示当前抽到的题目。每个概念每轮只出现一次，抽完整个题库才重新洗牌。抽题进度会保存在当前浏览器，刷新或重新打开页面后，下一次抽题会接着当前轮次继续。倒计时在页面重新打开后从新一题开始。

展开「添加自己的题目」可补充个人题目。网页会检查内置题、已添加题和部分常见别名。个人题目保存在当前浏览器中，并与内置题一起参与随机抽题。

## 贡献题目

公共题库在 `topics.js`。欢迎通过 Issue 反馈题目、计时或手机布局问题。也可以在分支上补充中文概念，再提交 Pull Request。请使用有明确检索线索的中文概念或名词短语，适合在有限准备时间内选取一个角度，用 1 分钟讲清楚。
