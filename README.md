# 一分钟即兴表达

一个中文即兴表达练习网页。随机抽取一个概念，例如「煤气灯效应」或「幸存者偏差」。用 10 分钟查资料、理思路，再用自己的话讲 1 分钟。准备好后也可以提前开讲。

## 使用

下载项目后用浏览器打开 `index.html`。点击「随机抽题」，选定题目后点击「开始准备」。准备倒计时结束后自动进入讲述，讲述完成后可以继续抽题。

题库包含 72 个概念。打开网页后，每个概念每轮只出现一次，抽完整个题库才重新洗牌。刷新页面会重新开始一轮抽题。

## 贡献题目

题库在 `topics.js`。欢迎通过 Issue 反馈题目、计时或手机布局问题。也可以在分支上补充中文概念，再提交 Pull Request。请使用简短的名词或名词短语，优先选择能在 10 分钟内查明含义、能用 1 分钟解释并举例的概念。
